🚪 `src/routes/` — Framework-specific страницы/файловый роутинг с доменами

---

🔧 `src/lib/` — Framework-agnostic инфраструктура

```
src/lib/
├── ui/                   # Переиспользуемые компоненты без бизнес-логики
└── server/               # Серверные утилиты и репозитории
   └── repo/              # Внешние источники данных
      ├── db/             # База данных (Drizzle ORM)
      ├── redis/          # Кэш и сессии
      ├── vault/          # Секреты и credentials
      └── keto/           # Авторизация (OpenFGA)
```
---
🍕 `scripts/` — Ваши полезные скрипты, утилиты и миграции
🚀 `setup/` — Сценарии, которые необходимо прогнать при запуске проекта
