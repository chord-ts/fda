## Основные принципы

<CardGrid stagger>
  <Card title="Фрактальность" icon="left-caret">
    Одинаковая структура на всех уровнях: компоненты → подмодули → домены → приложения
  </Card>
  <Card title="Разделение на слои" icon="down-caret">
    Четкое разделение: репозитории → модель → контроллер → UI
  </Card>
  <Card title="Явные контракты" icon="approve-check-circle">
    Каждый файл имеет строго определенную роль и набор экспортов
  </Card>
  <Card title="Framework-agnostic" icon="astro">
    Архитектура независима от фреймворка (Astro/SvelteKit/React/Vue)
  </Card>
</CardGrid>
